Production application icons live in this directory:

- `icon-source.png` is the generated high-resolution source artwork.
- `icon.ico` is used for Windows installers.
- `icon.icns` is used for macOS DMG and ZIP builds.
- `icon.png` is used for Linux AppImage and Debian builds.

The icon depicts a dungeon-map tile, d20, and forge/anvil motif for the Tableforge desktop app.
