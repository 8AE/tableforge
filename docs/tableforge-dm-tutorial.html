1. Tableforge Concepts

Tableforge has two synchronized views. The Dungeon Master portal is your private control room. It lets you manage boards, maps, tokens, hidden information, light, walls, doors, and audio. The Player viewer is the public table display. It shows the board you publish and hides DM-only content.

Project

A project is a campaign container. It holds boards, uploaded assets, token library entries, audio, and project-specific settings. Projects are stored on the host machine.

Board

A board is one scene, map, encounter, ship-combat field, or travel display. A project can have multiple boards, but players see only the board currently published to them.

Layer

The active layer decides what you can edit. Map handles background media, Token handles player-visible objects, GM handles private objects, and Wall/Lighting handles walls and doors.

Player Visibility

Tokens and drawings can be visible or hidden and can live on either the player layer or DM layer. Lighting adds another visibility gate by limiting what the player viewer reveals.

Core habit: prepare content on the DM side first, then publish only when the board is ready for players. The player viewer is a display, not your editing workspace.

2. Start A Campaign

Create a new project. Enter the campaign name in the text field and choose Create project. Use a name that is clear to future you, such as "Phandelver Friday Table" or "Stormwreck Isles Chapter 2".
Open an existing project. Click a project name in the list. The DM portal opens with that campaign's boards, assets, and saved table state.
Export before major changes. Use Export to download a zipped copy before deleting boards, replacing maps, or making major restructuring changes.
Import a campaign backup. Use Import Campaign to restore or move a campaign. If a project with the same identity already exists, Tableforge asks before overwriting it.
Host-machine rule: projects and assets live on the machine running Tableforge. If you move to another computer, export/import the campaign or copy the application data folder used by the desktop app.

3. Understand The DM Workspace

Top Bar

The top bar shows the active board name, board dimensions, grid type, active layer controls, player publication status, and the Open player view link. Click the board title to open the board drawer.

Quick Map Tools

The vertical quick menu on the left side of the map gives fast access to common tools. The visible hotkeys are V for select, T for token placement, D for drawing, M for ruler, and L for lighting.

Right Sidebar

The right sidebar has four major tabs: Board Items, Assets, Audio, and Board Setup. Resize it if you need more room while editing detailed token or board settings.

Active LayerSwitch between Map, Token, GM, and Wall/Lighting edit modes.Use GM for private prep and Token for content players should be able to see.
Board ItemsCreate tokens, edit selected tokens, manage drawings, and open the token library.Name tokens clearly so the sidebar remains useful during combat.

4. Prepare Boards

Create And Organize Boards

Click the board title in the top-left area to open the board drawer. Each board card represents a scene. The drawer lets you switch boards, duplicate a prepared board, delete a board, create a new 5 ft square board, create a 50 ft hex board, import from the Dungeon Builder, or import from 5e.tools.

Add a standard battle map. Choose 5 ft Square Board for most tactical encounters, dungeon rooms, wilderness fights, and town maps.
Add a large-scale scene. Choose 50 ft Hex Board for naval combat, air combat, overland travel, or maps where each cell represents a larger area.
Duplicate repeatable scenes. Duplicate a board when you want a variant of the same map with different token placement, weather, or encounter state.
Publish deliberately. Use the player ribbon or publication action only when the board is ready for players. The status label tells you whether players are live on the active board or another board.

Board Setup Fields

  • Name: use a scene name the players will not mind seeing if the board title is visible.
  • Grid: standard 5 ft square grid for tactical play, or 50 ft hex grid for vehicle and travel scenes.
  • Cells wide / Cells high: set the board footprint. Larger boards give more room but can be slower to navigate.
  • Cell pixels: controls rendered grid scale. Increase it for visual clarity; decrease it to fit larger maps.
  • Background media: upload an image or video and assign it to the active board.
  • Fit background to board: keep this on when the background should stretch to the exact board dimensions.
  • Scale, opacity, X offset, Y offset: use these when fit-to-board is off and you need manual alignment.

5. Assets And Audio

The Asset Manager is the safest place to bring files into a campaign. Uploaded files are stored with the project and become available to board backgrounds, token images, vehicles, and audio controls.

Asset Categories

Choose a category before uploading: Token, Map, Background music, Image, Video, or Audio. The category helps you find the asset later and controls common actions like using an image as a token or a map.

Drag-And-Drop Uploads

Drop files into the upload zone or browse from disk. Supported media includes PNG, JPEG, WebP, MP4, WebM, MOV, MP3, and WAV.

Use Assets In Play

  • Use Map on an image or video asset to apply it as the active board background.
  • Use Token on an image asset to set it as the image for newly placed tokens.
  • Use Choose from Project Assets in Board Setup to apply an already uploaded background.
  • Use Pick image from project assets on a token to reuse uploaded token art.

For music and ambience, upload MP3 or WAV files as audio assets, then switch to the Audio tab. Each audio asset appears with browser playback controls. Keep volume low enough that table conversation remains clear.

6. Tokens And Token Library

Tokens represent creatures, players, vehicles, ships, hazards, or any other object that should appear on the board. Token tools live primarily in the Board Items tab.

Place A Token

Choose the Token tool. Press T or click the plus icon in the quick menu.
Set the draft token fields. Choose token type, label, color, size, and image. On 50 ft hex boards, Tableforge uses 50 ft hex tokens.
Click the board. The token is placed on the active layer. If you are on the GM layer, the token starts as DM-only.
Select and refine. Click a token to edit label, color, size, image, visibility, layer, vision, and emitted light.

Token Types

Token TypeUse CaseNotes
Standard tokenCharacters, monsters, NPCs, furniture, hazards, and markers on 5 ft square grids.Size can represent larger creatures. Use images for portraits or top-down art.
Vehicle tokenShips, wagons, large monsters, moving platforms, or unusually shaped objects.Vehicle tokens have grid width, grid height, rotation, image scale, and image-position adjustment.
50 ft hex tokenShips and large-scale units on 50 ft hex boards.These occupy one hex cell and are only compatible with 50 ft hex boards.

Build A Reusable Token Library

The Token Library is project-wide. Save a selected board token when you want to reuse it across boards. You can also search a 5e.tools bestiary source, save a monster entry, and then import that token onto compatible boards. Library tokens retain useful defaults such as name, size, layer, vision, color, and token art when available.

DM-only prep: store ambush monsters, invisible NPCs, traps, or unrevealed terrain on the DM layer until the moment they should become visible. Move them to the player layer or toggle visibility when the scene changes.

7. Drawing And Measurement

Drawing tools are useful for spell areas, routes, labels, threat zones, room highlights, and quick table communication. Tableforge supports freehand drawing, rectangles, squares, circles, cones, and a ruler.

ToolTypical UseSession Tip
FreehandMark paths, sketch hazards, circle objects, or annotate a map.Use a bright color, then hide or delete when it stops being relevant.
Rectangle / SquareMark rooms, zones, spell effects, and cover areas.Use the player layer for visible effects and the DM layer for private planning.
CircleShow auras, explosions, spell radii, and sound zones.Keep the color consistent for recurring spell types.
ConeShow breath weapons, cones of cold, sight cones, and trap arcs.Confirm facing before publishing the effect to players.
RulerMeasure movement, ranges, distances, and vehicle spacing.Use it while adjudicating, then release it so the board remains uncluttered.

The Drawings list in the sidebar lets you select drawings, change layers, toggle visibility, and delete old marks. During a long combat, clear stale drawings regularly so players do not mistake old measurements for active effects.

8. Lighting, Walls, And Doors

Lighting is the main way to run exploration and line-of-sight scenes. When lighting is enabled, the player viewer darkens the board and reveals only areas exposed by token vision, token light, or manual reveal regions.

Lighting Setup Workflow

Enable board lighting. Turn on Enable board lighting in Board Setup or the lighting quick options. Set darkness to the desired level.
Draw light-blocking walls. Switch to Wall/Lighting and use the Wall tool to trace room boundaries, cliffs, dense foliage, or other blockers.
Place doors. Use the Door tool on boundaries where players can open, close, or encounter locked passages.
Configure token vision. Select player tokens and set bright vision, dim vision, emitted bright light, and emitted dim light.
Reveal manually when needed. Use Reveal / Hide for areas players should see even if token vision does not cover them, such as a narrated overview or known location.

Door States

Doors can be closed, open, or locked. Closed and locked doors block light. Open doors stop blocking light. Locked doors do not toggle open from normal player interaction until you unlock or change their state.

Prep warning: lighting is only as good as the walls you draw. Before a session, open the player view and confirm that important rooms, doors, and corridors reveal as expected.

9. Player Viewer

Open the player viewer from the DM top bar or by visiting the same host URL with ?view=player. Use it on the table display, projector, TV, second browser window, or another device on the same network.

Player Controls

  • Zoom: opens a zoom slider. Keyboard shortcuts +, -, and 0 adjust zoom from the player viewer.
  • Rotate: rotates the board in 90-degree increments for table-mounted displays or unusual screen placement.
  • Full screen: expands the player viewer. In fullscreen, the top bar hides until the pointer moves near the top of the screen.
  • Pan: drag the board when zoomed or when a large board does not fit the display.

Publish Boards To Players

The DM controls which board the player viewer displays. Use the board drawer to publish a board, or drag the player ribbon onto a board card. The top bar status tells you whether players are live on the active board. Use this status before revealing a surprise map.

10. Live Session Checklist

Before The Session

□Open the correct project and verify the expected boards exist.
□Export the project if you are about to run a major session or make risky edits.
□Check each board background, grid alignment, board size, and cell scale.
□Place player tokens, common NPCs, monsters, vehicles, and hidden DM-layer objects.
□Set token vision and emitted light for scenes that use lighting.
□Open the player view and verify the published board, zoom, rotation, and fullscreen behavior.
□Test any audio tracks you plan to use.

During The Session

  • Keep the player viewer open on the table display and the DM portal open on your private screen.
  • Use the board drawer to move players between scenes only when you are ready for them to see the new board.
  • Use GM-layer tokens for hidden enemies, traps, and notes. Move or reveal them when the fiction calls for it.
  • Use the ruler for quick rulings, then clear stale marks.
  • For exploration, reveal intentionally. Avoid drawing a giant reveal area unless the players should truly see that whole space.

After The Session

  • Clean up temporary drawings, old measurements, and one-off tokens.
  • Rename boards that changed purpose during play.
  • Export the campaign if the session created important state you want backed up.
  • Prepare the next published board before closing if the next session starts in the same scene.

Troubleshooting

ProblemLikely CauseFix
Player view says no project is open.The DM has not opened a project on the host.Open a project in the DM portal, then reload the player viewer.
Players see the wrong board.A different board is published.Open the board drawer and publish the intended board. Confirm the top bar says players are live here.
A token is invisible to players.It is hidden, on the DM layer, blocked by lighting, or not on the published board.Check token visibility, token layer, board publication, and lighting reveal state.
Background is misaligned.Board dimensions changed after the background was set, or fit-to-board is off.Turn on fit-to-board, or use scale and offsets while the Map layer is active.
Lighting reveals too much or too little.Missing walls, incorrect door state, token vision distances, or manual reveal regions.Inspect Wall/Lighting, selected token vision, and reveal areas in Board Setup.
Audio is missing.The file was not uploaded as an audio asset or the browser blocked playback until interaction.Upload MP3/WAV in Assets, then start playback manually from the Audio tab.
